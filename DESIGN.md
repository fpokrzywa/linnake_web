# Linnake website

Linnake is the unified successor incorporating ModelForge Studio capabilities and adding continuous fine-tuning. The website explains the full model lifecycle to solopreneurs and enterprise buyers. Enterprise agreements include customizable local LLMs on compatible desktops and laptops. Training requirements are distinguished from inference requirements. No pricing, availability date, performance result, or certification is invented.

## Visual direction

Palette: midnight #060b12, slate #101a27, ice #9ddaff, blue #64b8f4, silver #eef3f9, muted #a4b3c5. Segoe UI/system sans for text; Georgia for the Linnake wordmark. Wide left-aligned editorial sections with a prominent supplied metallic crest. Blue light comes from the reference image and controlled interface accents. No stock photography or generic icon cards.

The original logo composition is too detailed for navigation; use a text wordmark and reserve the supplied crest for the hero. Rather than recoloring ModelForge's existing page, build a new continuous-lifecycle narrative with an interactive feature explorer and a dedicated enterprise section.

Layout: navigation; split hero with crest; four-stage lifecycle explorer and labeled interface concept; dedicated continuous improvement explanation; enterprise local AI; individual and enterprise paths; FAQ; contact.

## Implementation decisions

Buildless accessible HTML/CSS/JavaScript, responsive and reduced-motion aware. Native details for FAQ, accessible lifecycle tabs, mobile navigation, native dialog for inquiries. Inquiry form creates an email draft; it does not imply server-side lead capture. Until a Linnake destination is supplied, use the verified existing ModelForge contact address, with explicit UI disclosure.

Source facts: user instructions and https://modelforge.studio/. The linked architecture plan was inaccessible. Continuous fine-tuning specifics are described as a product direction and consultation topic, not unverified autonomous deployment behavior. Dashboard is explicitly illustrative. New Sites hosting remains private for review.
